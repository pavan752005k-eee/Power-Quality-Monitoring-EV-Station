# Power Quality Monitoring & Compensation for EV Charging Station

## Overview
Simulation of a three-phase Active Power Filter (Shunt APF) 
to compensate harmonic distortion from EV charging loads.

## Tools Used
- MATLAB R2025b
- Simulink
- Simscape Electrical Specialized Power Systems

## Key Results
- Post-compensation THD: ~4.8% (below IEEE 519 limit of 5%)

## Concepts Applied
- p-q theory
- Park Transformation (abc→dq0)
- Hysteresis Current Control
- Capacitor Bank Switching
